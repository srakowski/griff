Releases are numbered like `v0.1.0` (`MAJOR.MINOR.PATCH`), and pre-releases like `v0.1.0-alpha.1`. Griff is pre-alpha for now: its releases are pre-releases, and a new version can change how projects and scripts work; the notes say what changed. Each release is the editor with the game players it exports with, the free fonts, the [license](https://github.com/srakowski/griff/blob/main/LICENSE) and the third-party notices, as an installer that keeps Griff up to date (a Griff installed from a pre-release takes newer pre-releases, and the first release after them) and as a portable zip.
