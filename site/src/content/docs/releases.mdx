Releases are numbered like `v0.1.0` (`MAJOR.MINOR.PATCH`). Griff is below 1.0 while it is young: a new minor version can change how projects and scripts work, and the notes say what changed. Each release is the editor with the game players it exports with, the free fonts, the [license](https://github.com/srakowski/griff/blob/main/LICENSE) and the third-party notices.
